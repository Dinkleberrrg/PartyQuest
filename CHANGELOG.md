# Changelog – PartyQuest

Versions follow `MAJOR.MINOR.PATCH`. Each release is a git tag `v<version>`; older versions can be downloaded from the tag page on GitHub.

## 1.2.0 – 2026-11-07
- Quest XP: shown behind the quest title in the quest log and the NPC quest window, and per member (at their level) in the side panel. New commands `/pq xp` and `/pq xprate N`. About 1,575 OctoWoW/Turtle quests have estimated XP, shown with `~`.

## 1.1.1 – 2026-10-03
- First tagged release (state of the OctoWoW install).
